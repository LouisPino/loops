    File format

    A sequence is a JSON object with a measures array. Each measure is the notation string you already write.

    {
  "title": "Section 1",
  "tempo": 72,
  "measures": [
    "3/8 + 3/32",
    "4/8",
    "2/8 + 1/16 + 1/8",
    "7/32 + 5/32",
    "6/8 *4",
    "6/16:5",
    { "notation": "3/8", "repeat": 2, "label": "B" },
    { "phrase": ["2/8", "3/8", "2/8 + 1/16"], "repeat": 3 }
  ]
}
    5/8
    Five eighths. Every one ticks.
    7/32
    A figure of seven 32nds. Only the first ticks.
    3/16
    Three 16ths. Only the first ticks.
    +
    Joins groups within one measure.
    *4
    Plays that measure four times. It stays one entry in the list.
    6/16:5
    Six 16ths at quintuplet speed — five in the time of four. Write :5:4 to spell the ratio out; left off, it is the power of two below, so :3 is three-in-two.
    phrase
    A run of measures that repeats as a block. The measures stay separate rows; the bracket down the right edge carries the count.

    A bare array of strings works too. Tempo is the quarter note; a tempo field in the file sets the dial the first time that file turns up. Switching between sequences afterwards leaves the dial where you put it.

    The dropdown

    It lists every sequence sitting next to index.html. After you add, rename, or delete a .json file in that folder, run:

    node sync.js

    That rewrites library.js, which is how the page knows what the folder holds — a page opened straight from disk isn’t allowed to look. If you serve the folder instead (python3 -m http.server), edits to a sequence show up on reload without syncing; only adding or removing files needs it. Dropping a file on the page still works and lands under “Opened”.
